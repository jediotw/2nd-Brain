# 📒 **Obsidian Notes Guide**  

Obsidian is a **Markdown-based** note-taking app that supports **LaTeX, backlinks, and advanced formatting**. This guide will help you quickly get started! 🚀  

---

## **1️⃣ Basic Markdown Formatting** 📝

| Feature        | Markdown Syntax |
|---------------|----------------|
| **Bold**      | `**Bold**` or `__Bold__` |
| *Italic*      | `*Italic*` or `_Italic_` |
| ***Bold Italic*** | `***Bold Italic***` |
| ~~Strikethrough~~ | `~~Strikethrough~~` |
| `Inline Code` | `` `Inline Code` `` |
| Code Block    | ``` ``` (triple backticks) |
| **Headings**  | `# H1` <br> `## H2` <br> `### H3` |
| Lists        | `- Item` (unordered) <br> `1. Item` (ordered) |
| Links        | `[Text](https://example.com)` |
| Images       | `![Alt Text](image.png)` |
| Blockquote   | `> This is a quote` |

---

## **2️⃣ Linking & Backlinks 🔗**

- **Link another note:** `[[Note Name]]`
- **Link to a heading inside a note:** `[[Note Name#Heading]]`
- **See all linked notes:** `Backlinks Panel` in Obsidian sidebar

---

## **3️⃣ LaTeX for Math & Equations** 🧮

- **Inline Equation:** `$E = mc^2$`
- **Block Equation:**
  ```
  $$
  \frac{a}{b} + \sqrt{x}
  $$
  ```
