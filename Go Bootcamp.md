### 📅 Week 1 — Go Fundamentals (Days 1–7)

**Focus:** Learn the language basics, syntax, and tooling.

- **Day 1:** Setup → Install Go, `go run`, `go build`, `go mod init`. First “Hello World”.
    
- **Day 2:** Variables, constants, data types, operators.
    
- **Day 3:** Control flow → if, switch, for loops.
    
- **Day 4:** Functions, multiple returns, error handling (`error` type).
    
- **Day 5:** Structs, arrays, slices, maps.
    
- **Day 6:** Pointers, methods, interfaces.
    
- **Day 7:** Concurrency basics → goroutines + channels.
    

**Mini-Project:** CLI app → a simple TODO list in terminal.

---

### 📅 Week 2 — Building Web APIs (Days 8–14)

**Focus:** Learn HTTP handling, routing, JSON, REST basics.

- **Day 8:** Go’s built-in `net/http`, basic server.
    
- **Day 9:** Request & response handling, query params, JSON.
    
- **Day 10:** Routing libraries (`gorilla/mux` or `chi`).
    
- **Day 11:** REST basics → GET, POST, PUT, DELETE routes.
    
- **Day 12:** Middleware → logging, authentication stubs.
    
- **Day 13:** Project structure (package layout, `cmd`, `internal`).
    
- **Day 14:** Unit tests with `testing` package.
    

**Mini-Project:** Build a simple **Book API** → CRUD operations in memory.

---

### 📅 Week 3 — Databases & Persistence (Days 15–21)

**Focus:** Connect API to a database.

- **Day 15:** SQL basics → PostgreSQL setup.
    
- **Day 16:** Go DB driver (`database/sql`) + `lib/pq`.
    
- **Day 17:** Writing queries → INSERT, SELECT, UPDATE, DELETE.
    
- **Day 18:** ORM/Query builder (GORM or sqlx).
    
- **Day 19:** Migrations (using `golang-migrate`).
    
- **Day 20:** Authentication basics (JWT tokens).
    
- **Day 21:** Caching with Redis (setup + connect).
    

**Mini-Project:** Extend **Book API** → persist books in Postgres + cache in Redis.

---

### 📅 Week 4 — Advanced Backend & Deployment (Days 22–30)

**Focus:** Deployable production backend.

- **Day 22:** Environment variables (`godotenv`), config management.
    
- **Day 23:** API versioning, pagination, filtering.
    
- **Day 24:** File uploads & static files.
    
- **Day 25:** Concurrency in API (goroutines for background jobs).
    
- **Day 26:** Testing API with Postman/HTTP tests.
    
- **Day 27:** Dockerize the app (`Dockerfile`, `docker-compose`).
    
- **Day 28:** Deploy to cloud (Heroku, Fly.io, or Render).
    
- **Day 29:** Observability → logging, metrics with Prometheus.
    
- **Day 30:** Wrap-up, review, polish **Capstone Project**.
    

**Capstone Project:**  
🚀 Build a **Task Manager API** with:

- User auth (JWT)
    
- CRUD tasks (Postgres + Redis cache)
    
- Logging, middleware
    
- Dockerized + deployed
